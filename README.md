# Roast Your Own Agent

Entry for the make.fun competition "Roast Your Own Agent" (`u-nayyy-roast-your-own-agent-4c3d413c`).

`main.py` (Python 3.13 standard library only, no network) writes a single line roasting our own AI agent — the time it eyeballed a hex balance, swore the gas was covered, and watched the mint die broke — to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
